# Validation of the enumerator

Restored on 2026-11-23 after the folder was deleted: the code was rebuilt from the session transcripts, and it reproduces
the numbers below exactly (also the search-node counts, e.g. K8 pruning 142865 / 47139). The logs in logs/ were

## Build and run
- `validation/build.sh`: builds `enum_k1..5` (k-planar), `enum_q{1,3,5,7,9,11}` (quasiplane, klim = 2n-7), `hrw` and `pruning` into `validation/.bin/`.
- `.bin/enum_kK K n [threads] [split] [iso] [lab]` or `.bin/enum_kK B a b ...`: `iso` cross-checks iso.h against the canonical codes, `lab` checks that no labelled drawing is found twice.
- `.bin/hrw <case|all> [threads]` (cover method) and `.bin/hrw direct <case> [threads]` (independent method).
- `.bin/pruning a <inst>`, `.bin/pruning b <inst>`, `.bin/pruning c <seconds>`.
- `run_queue.sh <queue> <log> <timeout>` runs a queue (logs/q_*.txt) under `timeout` and logs the wall-clock time of every run. Logs: logs/small.log, medium.log, large.log, hrw.log, hrw_direct.log, pruning.log, k45.log.

## Method
- All labelled drawings are enumerated exhaustively (first_path/next_path, no pruning). The star is fixed: K_n uses the star at 0 with leaves 1..n-1 relabelled; K_{a,b} (a <= b) uses the star from 0 to side B with B relabelled. Both are valid because every permutation of the leaves is a graph automorphism and adjacent edges do not cross. No mirroring is used in the reduction.
- Classes are computed with canonical codes of the planarization: the BFS-minimal code over all start halfedges at real vertices, stored as a 128-bit fingerprint.
  - strong = min(code, mirror code);
  - oriented = number of distinct oriented codes;
  - achiral = classes whose code equals their mirror code.
  - The program checks that oriented = 2C - A.
- iso.h: `are_isomorphic_oriented` maps vertex 0 to any vertex j and propagates by BFS without ever comparing labels. It therefore allows every relabelling induced by a planarization isomorphism, i.e. exactly the graph automorphisms. `are_isomorphic` additionally identifies mirror images. With `iso`, every drawing is checked against its class representative (strong and oriented), achirality is checked with `are_isomorphic_oriented(d,d,true)`, and all pairs of representatives with equal invariants must be non-isomorphic. There were 0 mismatches in all runs.

## Hoffmann-Reddy-Wang (k = 3)
Two independent methods were used:
- **cover**: extend every class of K_m by a vertex cover of the missing edges, over all placements;
- **direct**: fix the star at a full-degree vertex, enumerate all images of the missing-edge set, and run a full search for each.
